# Prisma Migrations

This directory contains database migrations generated by Prisma.

## Running Migrations

To run migrations in development:
```bash
npx prisma migrate dev --name init
```

To generate the Prisma Client:
```bash
npx prisma generate
```

## Migration History

- `init` - Initial schema with Users, Rooms, Passages, Games, and GameSessions tables with indexes on room_id, user_id, and game_id
